## Neutral Conclusion

The calibration run succeeded and produced comparable evidence for the four pre-registered variants. Hybrid RRF improved Top-3 and Top-5 coverage relative to the dense baseline but slightly reduced Top-1 and was only modestly slower. The cross-encoder variants preserved candidate recall but introduced substantial latency and did not improve aggregate Top-1 on this calibration run. These results are evidence for later design discussion, not a final production architecture selection.
